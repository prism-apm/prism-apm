# prism-apm-ui

`prism-apm-ui` is the frontend page module for Prism APM.

## Local Development

```bash
npm install
npm run dev
```

Default development server:

```text
http://127.0.0.1:8066
```

## Production Build

```bash
npm run build
```

Build output:

```text
dist/
```

For complete deployment and reverse proxy configuration, see:

- [Prism APM Deployment Guide](../docs/en/deployment.md)
