# 拓扑图

拓扑图用于展示当前时间范围内服务、数据库、缓存、消息队列等组件之间的调用关系。通过节点和有向边，可以快速判断服务依赖链路、上下游影响范围以及异常调用集中在哪些路径上。

页面入口：

1. 登录 APM UI。
2. 打开 `http://localhost:8066/#/topology/list`，或从左侧菜单进入“拓扑图”。
3. 在顶部选择时间范围后，页面会按当前时间窗口加载拓扑数据。

![拓扑图](../../assets/zh-CN/quickstart/topology.png)

# 功能说明

拓扑图以“节点 + 边”的方式展示调用关系：

- 节点表示一个可观测对象，例如服务、数据库、Redis、MQ 等。
- 边表示两个节点之间存在调用关系，箭头方向表示调用方向。
- 鼠标悬停节点时，会临时高亮该节点的入边和出边，便于区分上游与下游。
- 单击触发告警的边时，可以查看该边命中的告警规则和当前指标数据。
- 右键节点可以打开操作菜单，对节点和关联边进行锁定、隐藏、显示或重置。
- 右键边可以单独隐藏该边。

拓扑图适合用于以下场景：

- 查看系统整体架构情况。
- 排查服务异常时，查看异常服务依赖了哪些下游组件。
- 分析故障影响范围时，确认哪些上游服务会受到影响。
- 拓扑节点较多时，锁定或隐藏无关节点，让画布只保留当前排查路径。
- 结合高亮规则，快速发现调用次数、响应时间、错误数异常的服务或依赖边。

# 页面控件

顶部公共筛选区会影响拓扑数据查询：

| 控件 | 说明 |
| --- | --- |
| 时间范围 | 默认显示最近 30 分钟，也可以选择自定义时间范围。拓扑数据会按该时间范围重新查询。 |
| 时区 | 控制时间范围的解释方式，默认使用当前界面时区。 |
| 刷新 | 按当前时间范围重新加载拓扑数据。 |
| 语言 | 支持中文和英文界面切换。 |
| 分享 | 复制当前页面链接，便于分享当前视图。 |

拓扑图画布上方还提供以下操作：

| 控件   | 说明                                        |
| ---- | ----------------------------------------- |
| 当前布局 | 显示当前图布局类型。当前支持 `dagre`、`grid` 和 `force2`。 |
| 切换布局 | 在不同布局之间切换，用于调整节点排列方式。                     |
| 重新布局 | 按当前布局重新计算节点位置。                            |
| 高亮规则 | `TBD`. 打开拓扑高亮规则列表，用于维护告警和高亮条件。            |
| 节点搜索 | 输入或选择节点名称后，画布会聚焦到该节点，并短暂高亮节点标签。           |
| 放大   | 放大拓扑画布。                                   |
| 缩小   | 缩小拓扑画布。                                   |
| 适应视图 | 将当前可见拓扑自动缩放到画布范围内。                        |

# 图元素说明

边表示调用关系。默认边为蓝色虚线，并带有方向箭头。节点悬停或锁定后，入边和出边会使用不同颜色高亮：

| 状态   | 说明                       |
| ---- | ------------------------ |
| 入边高亮 | 表示调用当前节点的上游关系。           |
| 出边高亮 | 表示当前节点调用下游的关系。           |
| 锁定高亮 | 将当前高亮关系固定在画布上，鼠标移开后仍然保留。 |


# 节点右键菜单

在拓扑节点上右键，可以打开节点操作菜单。菜单分为“锁定与解锁”“显示与隐藏”“全局操作”三类。

## 锁定与解锁

| 菜单项     | 功能说明                               | 适用场景                     |
| ------- | ---------------------------------- | ------------------------ |
| 锁定关联节点  | 锁定当前节点的关联关系。锁定后，当前节点的入边和出边会保持高亮状态。 | 需要固定查看某个服务的上下游调用关系时使用。   |
| 解锁关联节点  | 解除当前节点关联边的锁定状态，让这些边恢复普通显示。         | 排查完成后，取消固定高亮。            |
| 仅显示锁定节点 | 只保留当前节点及其已锁定关联范围，隐藏无关节点和无关边。       | 拓扑节点较多时，用于减少干扰，聚焦当前排查对象。 |

“仅显示锁定节点”适合在复杂拓扑中快速收敛视图。使用方式通常是：右键目标节点，选择“仅显示锁定节点”，画布会隐藏与当前排查路径无关的节点和边，并自动重新布局。

## 显示与隐藏

| 菜单项 | 功能说明 | 适用场景 |
| --- | --- | --- |
| 隐藏边 | 隐藏当前节点的所有关联边，节点本身仍保留在画布上。 | 暂时不关注某个节点的调用关系，只想保留节点位置时使用。 |
| 显示边 | 显示当前节点的关联边。只有边两端节点都处于可见状态时，边才会恢复显示。 | 手动恢复刚才隐藏的关联边。 |
| 隐藏当前节点及边 | 隐藏当前节点及它直接关联的边。如果某个关联节点因此没有其他可见边，也会一起被隐藏；不会继续隐藏更下游节点的其他关系。 | 需要从画布中移除当前节点，降低视图复杂度。 |
| 显示关联节点 | 显示当前节点的直接关联节点，并恢复它们与当前节点之间的直接边；不会展开关联节点更下游或更上游的其他边。 | 隐藏部分节点后，需要把当前节点的一层关联关系找回来。 |


## 全局操作

| 菜单项   | 功能说明                         | 适用场景                          |
| ----- | ---------------------------- | ----------------------------- |
| 重置拓扑图 | 清除锁定状态，显示所有节点和边，重新布局并适应画布视图。 | 当画布经过多次隐藏、锁定或缩放后，需要恢复到初始拓扑状态。 |
