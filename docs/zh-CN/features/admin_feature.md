# 功能说明

管理权限用于维护 APM UI 中的账号、角色、权限和项目访问范围。管理员可以通过“系统管理中心”完成用户开通、角色授权、项目分组和访问回收。

系统管理中心包含三个入口：

- 权限管理：维护用户、角色和权限。
- 访问分配：维护用户与角色、角色与权限、用户与项目组之间的关系。
- 项目管理：维护项目、项目组，以及项目归属关系。

管理权限主要控制两件事：

- 用户能不能进入某些功能或执行某些管理操作。
- 用户能不能查看某些项目或服务的数据。

# 使用场景

当团队中不同用户需要不同访问范围时，可以使用管理权限。

常见场景包括：

- 为新用户开通 APM 系统账号。
- 创建管理员、运维、开发等角色。
- 控制哪些角色可以访问管理功能。
- 控制普通用户只能查看自己负责的项目或服务。
- 用户离岗或职责调整时，移除角色或项目组关系。

# 权限关系说明

用户访问 APM 时，会同时受到“角色权限”和“项目权限”影响。

- 用户：登录 APM UI 的账号。
- 角色：一组功能权限，例如管理员角色或普通查看角色。
- 权限：角色可访问的功能范围，页面中以“权限名称”和“权限 URL”维护。
- 项目：APM 中的项目或服务，项目名称通常对应服务名称。
- 项目组：一组项目的集合，用于批量授权给用户。

可以按下面两条关系理解授权结果：

```text
用户 -> 角色 -> 权限 -> 可使用的功能
用户 -> 项目组 -> 项目 -> 可查看的数据
```

只给用户分配角色，不代表用户一定能看到项目数据；还需要把用户加入包含目标项目的项目组。

# 使用方式

进入管理中心：

1. 登录 APM UI。
2. 打开 `http://localhost:8066/#/admin/dashboard`。
3. 根据需要进入“权限管理”“访问分配”或“项目管理”。

# 权限管理

“权限管理”页面包含三个页签：

- 用户管理：新增、编辑、删除用户；用户列表展示 ID、用户名、启用状态、创建时间和操作按钮。
- 角色管理：新增、编辑、删除角色；角色列表展示 ID、角色名称、创建时间和操作按钮。
- 权限管理：新增、编辑、删除权限；权限由权限名称和权限 URL 组成，例如 `/api/admin/**`。

删除用户、角色或权限前，需要先移除相关分配关系。否则后端会拒绝删除，避免产生悬空授权。

# 访问分配

“访问分配”页面包含三个页签：

- 用户角色分配：选择用户和角色，建立用户到角色的关系。
- 角色权限分配：选择角色和权限，建立角色到功能权限的关系。
- 项目组用户分配：选择项目组和用户，控制用户可查看哪些项目组下的项目数据。

每个分配页签都支持查看已有关系、刷新列表和移除关系。

# 项目管理

“项目管理”页面包含三个页签：

- 项目管理：新增、编辑、删除项目；项目包含项目名称和显示名称。
- 项目组管理：新增、编辑、删除项目组。
- 项目组项目分配：选择项目组和项目，建立项目归属关系。

项目名称通常对应 APM 数据中的服务名称。普通用户只能查看被分配项目组中的项目；`ADMIN` 用户可以查看全部项目。

# 推荐授权流程

首次配置一个普通用户时，建议按以下顺序操作：

1. 在“项目管理”中创建项目。
2. 在“项目管理”中创建项目组。
3. 在“项目组项目分配”中把项目加入项目组。
4. 在“权限管理”中创建角色，或确认已有合适角色。
5. 在“权限管理”中创建权限，或确认已有合适权限。
6. 在“访问分配”中把权限分配给角色。
7. 在“权限管理”中创建用户。
8. 在“访问分配”中把角色分配给用户。
9. 在“访问分配”中把用户加入项目组。
10. 使用该用户登录并检查可访问的功能和项目数据。

如果只给用户分配功能权限，但没有分配项目组，用户可能可以进入相关功能，但服务列表或服务详情中看不到目标项目数据。

# 使用注意事项

- 权限变更后可能不会立刻体现在访问结果中。新增、修改或移除角色权限后，最多等待约 60 秒再让用户重试。
- 页面上的“刷新”按钮用于刷新当前列表数据；如果是验证用户是否已获得访问权限，建议切换到对应用户重新登录或刷新业务页面后再检查。
- 删除用户、角色、权限、项目或项目组前，需要先移除已有分配关系。
- 普通用户需要同时具备功能权限和项目权限，才能正常查看对应服务数据。

# 故障排查

如果访问被意外拒绝，请按顺序检查：

- 用户是否已登录，登录状态是否过期。
- 用户是否启用。
- 用户是否已分配正确角色。
- 角色是否已分配对应功能权限。
- 权限变更后是否已等待约 60 秒。
- 普通用户是否已加入包含目标项目的项目组。
- 目标项目名称是否与 APM 数据中的服务名称一致。

如果管理员也无法访问管理功能，请确认系统中是否存在 `ADMIN` 角色，且当前用户已经分配该角色。
