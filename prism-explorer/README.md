# Prism Explorer

> Prism Explorer is a zero-configuration interactive demo based on mock telemetry data. It lets you try the core features of Prism APM.

## Quickstart

### Prerequisites

- Docker Desktop
- Java 21
- Node.js

### Start

Open PowerShell **as Administrator** and run:

```powershell
.\build-and-up.ps1
```

The script automatically builds the Java modules, builds the frontend, and starts Docker Compose.

### Access

After startup completes, open **http://localhost/** in your browser.
